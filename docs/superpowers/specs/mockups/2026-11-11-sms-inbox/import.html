How uploading works

  • The file is your own list. There is no link to any other system.
  • A number already in contacts is not added twice.
  • A number that replied STOP stays marked opted out.
  • Lines that are not a Philippine mobile are refused and listed.
  • Recorded with your name and the counts, never a name.
